# Mouse Coding Toolbar

**Vibe Coding 时懒得动键盘？常用操作，鼠标点几下就行。**

Mouse Coding Toolbar 是个 Windows 悬浮工具栏。用 ChatGPT、ZCode 这类 AI 编程工具时，经常要回一句「继续」「检查一下」，或者把刚复制的报错贴回对话框。工具栏就贴在输入框旁边，这些小操作顺手点一下就能完成。

Mouse Coding Toolbar is a Windows utility for mouse-only Vibe Coding. Keep text shortcuts, voice input, and clipboard history next to your chat box. Built with AutoHotkey v2.

![license](https://img.shields.io/badge/license-MIT-green)

## 核心功能

- **自定义输入项**。把「继续」「检查一下」或一整段常用提示词做成按钮。每个按钮的名字和内容都能改。
- **仅填入或直接发送**。每个按钮都能设定是只把文字填进输入框，还是填入后自动回车。悬停时也能临时选用另一种方式。
- **语音输入快捷键**。把语音按钮绑定到你正在用的输入法快捷键，支持点一下开关，也支持按住说话。
- **剪贴板快速粘贴**。把鼠标停在「↑ 发送」上，点一条最近复制的内容，就能粘贴进输入框。历史列表最多保留 10 条去重文本。

工具栏跟随已识别的输入框，切走焦点后自动隐藏。内置 ChatGPT 和 ZCode 桌面客户端预置项，也可在设置里添加目标应用。工具在本地运行。

## 环境要求

- Windows 10 / 11
- [AutoHotkey v2](https://www.autohotkey.com/)（v2.0 以上）

## 快速开始

1. 下载仓库（`git clone` 或 Download ZIP 解压），保持文件相对位置，双击 `QuickToolbar.ahk` 启动，出现托盘图标即成功。
2. 打开设置（托盘右键 → 设置），在「目标应用」确认要启用工具栏的应用进程名（默认 `chatgpt.exe, zcode.exe`，改成你自己的应用即可）。
3. 点击该应用的对话/消息输入框，按 **Ctrl+Alt+F8** 校准，工具栏会记住这个输入框。校准一次即可，之后所有会话、生成中都有效。
4. 点进输入框 → 工具栏出现；点按钮填入文字，悬停「↑ 发送」看剪贴板历史，按住语音说话。

## 使用说明

### 按钮

| 默认按钮 | 行为 | 颜色 |
| --- | --- | --- |
| 继续 | 填入「继续」并**自动回车发送** | 悬停浅蓝，按下加深 |
| OK / 执行 / 检查 / 提交 | 仅填入文字，不发送 | 悬停浅灰，按下加深 |
| 合并 | 仅填入文字，不发送 | 悬停浅灰，按下加深 |
| ↑ 发送 | 单独发送一次 Enter（点击）；悬停后弹出**剪贴板历史面板** | 悬停浅绿，按下加深 |
| 语音 | 模拟语音输入法快捷键（默认 Win+H） | 悬停浅绿，按下加深 |

- 设置里可新增 / 删除 / 调序按钮，编辑名称、多行内容、快捷键，逐按钮勾选「填入后回车」。
- 快捷键格式：`!1` = Alt+1，`^+K` = Ctrl+Shift+K，`^!F9` = Ctrl+Alt+F9，留空禁用，也可统一关闭。
- 粘贴使用系统剪贴板，操作完成后自动恢复之前的内容；不会保存对话或剪贴板内容到任何文件。

### 目标应用与校准

- 工具栏只在目标应用里出现。设置 →「目标应用」填进程名（逗号分隔，如 `chatgpt.exe, zcode.exe`）。Microsoft Store 版应用可能需要包名规则，见 `defaults.tsv` 中 chatgpt 行的第 4 列。
- 换应用、界面改版后输入框认不出时：点进输入框按 Ctrl+Alt+F8 重新校准。识别签名只取稳定的控件结构（忽略占位文案、React 动态 id 等），一次校准全状态通用。
- 托盘菜单 →「诊断输入框」可查看未识别的具体原因。

### 语音快捷键

- 设置 → 语音输入快捷键 →「录制」→ 直接按下想要的组合键。支持修饰键组合（Alt+V、Win+H…）和**单独的左右 Alt / Ctrl / Shift / Win**（左右区分）。
- **短按**按钮发送一次完整快捷键（适合"按一下开、再按一下关"的输入法）；**按住**超过约 0.25 秒持续按住快捷键，松开时释放（适合"按住说话"的输入法）。两种方式自动按按键时长区分，无需配置。

### 拖动与位置

- 按住工具栏任意位置拖动，松手自动记住相对输入框的位置（含多显示器 / 缩放适配）。
- 设置里可恢复默认位置、调整按钮宽高、不透明度、是否始终置顶、开机自启。

## 配置文件

按钮、目标应用、校准记录保存在 `%LOCALAPPDATA%\MouseCodingToolbar\settings.tsv`（旧版本自动从 `CodexQuickToolbar` 迁移）。恢复默认：退出工具后改名该文件再启动。`defaults.tsv` 是出厂默认配置。

## 隐私

工具完全本地运行，不联网、不上传；语音输入由系统/输入法自身完成。
